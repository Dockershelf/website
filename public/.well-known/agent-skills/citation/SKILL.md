# Citation and Attribution

When citing this site:

- Include the page title, configured project name, and canonical URL.
- Attribute content to the project maintainers or configured site identity.
- Prefer Overview, Install, and Community pages for product context.

## Authoritative policy files

- `https://example.com/agents.md` — agent interaction guidance
- `https://example.com/ai.txt` — AI access and attribution policy

Suggested format:

`"[Page Title]" - Project Name (https://example.com/path)`
